E-Commerce Sales Dashboard

A comprehensive Power BI report designed to analyze the complete sales performance of an e-commerce business. Power BI · Logistics Analytics · 2025

Transport Delivery Performance Dashboard

An enterprise-grade operational Power BI dashboard for a logistics and transport business. Enables operations managers to track delivery performance, identify delay patterns, monitor driver productivity, and optimize route efficiency — all through real-time interactive filtering.

The dashboard includes advanced DAX measures including calculated on-time percentage, fuel efficiency ratios, and route-wise aggregations. Scatter charts were used to visualize the relationship between route distance and fuel consumption across states.

Tracked 500 deliveries with on-time rate, delay analysis, and trend monitoring
Built driver performance scorecard table with custom DAX measures
Created fuel usage by state pie chart and route efficiency scatter plot
Implemented month, driver, and state slicers for operational drill-down
Designed clean, business-focused visual layout and color theme
